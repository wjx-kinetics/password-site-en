      Good to know

      • The password you type is sent over HTTPS to the Python server running this site and thrown away as soon as the calculation ends. It is not stored or logged.
      • The times are estimates. Real attack speed depends heavily on how a site stores passwords.
      • Even a strong password fails everywhere at once if you reuse it and one site leaks. Use a different one on every site and turn on two-step verification.
